## 1. DOSL GATEとは

展示会の「事前登録 → QRチケット発行 → 当日受付チェックイン → 登録者管理」を提供するマルチテナントSaaS。1つのシステムで複数の展示会（複数の主催者）を運用できる。

| 利用者 | 使う画面 | 認証 |
|--------|---------|------|
| 来場者 | 登録フォーム・QRチケット | 不要（チケットコードがアクセストークン） |
| 主催者・受付スタッフ | 管理画面 `/admin/...` | メール+パスワード |
| 出展社（オプション） | リードスキャン `/exhibitor/...` | アクセスコード |

---

## 2. 来場者の流れ

1. **事前登録**: `https://dosl-gate.vercel.app/{展示会slug}/register` を開き、氏名・メール・会社情報等を入力して登録
   - 必須項目は展示会ごとの設定（`form_fields`）で変わる
   - 同じメールで再登録すると「既に登録済みです」となり、既存のチケットコードが案内される（上書き登録はされない）
2. **確認メール**: 登録完了と同時にチケットコード・QRチケットへのリンク入りのメールが自動送信される
3. **QRチケット**: `https://dosl-gate.vercel.app/{slug}/ticket/{チケットコード}` でいつでも表示可能。当日はこの画面（またはメール）を受付で提示

チケットコードは8文字の英数字（紛らわしい文字は除外済み）。

## 3. 管理画面の使い方

### 3.1 ログイン

- `https://dosl-gate.vercel.app/admin/login` からメール+パスワードでログイン
- 現在の管理者: mituhi3216@gmail.com（パスワードは大西さん保管）
- セッションは24時間（自動更新は7日間）。切れたら再ログイン

### 3.2 ダッシュボード（/admin/dashboard）

- サマリーカード: 展示会数 / 総登録者数 / 総入場者数
- 展示会一覧: 開催期間・ステータス（下書き/公開中/終了/アーカイブ）・登録数・入場数

### 3.3 登録者管理（/admin/registrations）

- 一覧表示・キーワード検索・登録種別/ステータスでのフィルター
- 行の「編集」から来場者情報の修正・キャンセル処理（モーダル）
- 「メール送信」ボタンで確認メールの手動再送
- 「CSVダウンロード」で登録者一覧をCSV出力（Excelで開ける・数式インジェクション対策済み）

### 3.4 受付チェックイン（/admin/checkin）

当日の入場受付に使う。スマホ・タブレット・PCどれでも可。

- **QRカメラモード**: カメラで来場者のQRを読み取る（背面カメラ自動選択）
- **手動入力モード**: チケットコード8文字を手打ち（小文字は自動で大文字化）

結果表示の見方:

| 表示 | 意味 | 対応 |
|------|------|------|
| 緑 | 初入場OK | そのまま入場案内 |
| 黄 | 再入場（既に入場済み） | 再入場として案内（不審な場合は本人確認） |
| 赤 | エラー（コード不明・キャンセル済み等） | メッセージを確認して対応 |

同じQRの連続読み取りは3秒間ブロックされる（二重登録防止）。

## 4. 新しい展示会を作る（現状はSQLで登録）

展示会の作成UIは未実装のため、**SupabaseダッシュボードのSQL Editorで登録**する。

1. https://supabase.com/dashboard でプロジェクト `dosl-gate-setup` を開く
2. SQL Editor で `supabase/seed.sql` を雛形に、以下の3点セットを INSERT する
   - `organizations`（主催者。既存の主催者の展示会追加なら不要）
   - `exhibitions`（展示会本体。slug が登録URLになる）
   - `registration_types`（登録種別。例: 一般来場者/VIP/プレス）
3. 登録フォームの項目は `exhibitions.form_fields`（JSON）で制御する

```jsonc
// form_fields の例: visible=フォームに表示するか, required=必須か
{
  "company_name": {"visible": true,  "required": true},
  "company_kana": {"visible": true,  "required": true},
  "department":   {"visible": true,  "required": false},
  "position":     {"visible": true,  "required": false},
  "phone":        {"visible": true,  "required": false},
  "postal_code":  {"visible": false, "required": false},
  "address":      {"visible": false, "required": false}
}
```

4. `exhibitions.branding`（JSON）でメインカラー・コピーライト表記を設定（登録画面・チケット・メールに反映）
5. `exhibitions.features`（JSON）でオプション機能のON/OFF: `{"seminar": true, "lead_retrieval": false, "companion": false}`
6. 登録後、`https://dosl-gate.vercel.app/{slug}/register` を開いて表示・テスト登録で確認する

ステータスは `published` にしないと登録を受け付けない（`draft` のままだとフォームが開けない）。

## 6. GATEオプション（セミナー管理・リードリトリーバル）

**2026-07-08 本番反映済み**（005適用・デプロイ完了）。利用するには展示会ごとに `features` フラグ（seminar / lead_retrieval）をONにする（→ 4章の5）。

### 6.1 セミナー管理（features.seminar が true の展示会のみ）

| 画面 | 用途 |
|------|------|
| `/admin/seminars` | セミナーの作成・編集（日時/講演者/会場/定員） |
| `/admin/seminars/{id}` | 予約数・聴講数・聴講率と予約一覧・CSV |
| `/admin/seminars/checkin` | セミナー会場での当日受付（入場証QRを読むと聴講記録） |

- 来場者は事前登録フォームでセミナーを同時予約できる（定員超過は自動で拒否）
- 受付の色分けは入場チェックインと同じ（初回=緑/受付済=黄/エラー=赤）

### 6.2 リードリトリーバル（features.lead_retrieval が true の展示会のみ）

出展社がブースで来場者の入場証QRをスキャンし、リード情報を取得する機能（出展社課金モデル）。

- 管理者: `/admin/exhibitors` で出展社を登録し、**アクセスコード**（12文字）を発行して出展社に渡す
- 出展社: `/exhibitor/login` にアクセスコードでログイン → `/exhibitor` で来場者QRをスキャン → `/exhibitor/leads` で一覧・商談メモ・CSV
- コードの無効化（is_active=false）で即時利用停止できる
- 個人情報の扱い: 出展社が取得するのは「スキャンした来場者」の情報のみ

**個人情報の同意取得（2026-07-08 実装・2026-07-10 本番反映済み）**:

- `features.lead_retrieval` がONの展示会では、登録フォームに「個人情報の取り扱いについて」の説明＋**必須の同意チェックボックス**が自動表示される（文言・仕様は requirements.md 22.5）
- 同意しないと登録できない（フォーム・API両方で検証）。同意日時は登録データに記録される
- lead_retrieval がOFFの展示会では表示されず、従来どおり登録できる
- 2026-07-10 本番デプロイ済み（コミット ad58c69・実ブラウザ検証済み）

**リード機能を使い始める手順（展示会ごと）**:

1. Supabase SQL Editor で features をON:
   `UPDATE exhibitions SET features = features || '{"lead_retrieval": true}'::jsonb WHERE slug = '<対象slug>';`
2. `/admin/exhibitors` で出展社を登録し、アクセスコードを各出展社に配布
3. 登録フォームを開き、同意ブロックが表示されることを確認

## 8. よくあるトラブル

| 症状 | 確認・対処 |
|------|-----------|
| 登録フォームが開かない | 展示会の `status` が `published` か確認 |
| 「登録種別を選択してください」で進めない | その展示会に `registration_types` が登録されているか確認 |
| 確認メールが届かない | 5.3 の手順。ドメイン認証前は本人宛以外に届かない点に注意 |
| 管理画面にログインできない | Supabase Auth のユーザーと `admin_users`（is_active=true）の両方があるか確認 |
| チェックインで「キャンセル済み」エラー | 登録者管理で該当者のステータスを確認（正しい挙動の可能性） |
| QRカメラが起動しない | https でアクセスしているか・ブラウザのカメラ許可を確認。手動入力モードで代替可 |
