# DOSL GATE セキュリティ説明資料（企業情シス向けQ&A）

作成日: 2026-07-13 ／ 対象: DOSL GATE（事前登録・QR受付システム https://dosl-gate.vercel.app）

## 1. システム構成と個人データの流れ

```
来場者（ブラウザ）
  → Vercel（アプリ実行基盤・常時TLS）
  → Supabase PostgreSQL（データ保存・保存時暗号化）
  → HubSpot CRM（フォローアップ用・毎日1回バッチ同期）
```

**取得する個人情報**: 氏名・フリガナ・メールアドレス・会社名・部署・役職・電話番号・業種・来場目的（展示会ごとに項目は可変。本人入力のみ、要配慮個人情報は取得しない）

**委託先（データ処理者）一覧**

| 事業者 | 用途 | 保存/処理場所 | 主な認証 |
|---|---|---|---|
| Supabase Inc. | データベース（個人情報の保存先） | **日本（AWS東京）** | SOC 2 Type II, HIPAA対応 |
| Vercel Inc. | アプリ実行基盤（保存なし・処理のみ） | 米国 | SOC 2 Type II, ISO 27001 |
| Resend | 登録確認メール送信 | 米国 | SOC 2 Type II |
| HubSpot Inc. | 顧客管理（CRM・同意済み登録者のみ） | 米国 | SOC 2 Type II, ISO 27001 |

## 2. セキュリティ対策一覧（レイヤー別）

### 通信・保存
- 全通信をTLSで暗号化（HTTPS強制。ブラウザ〜サーバー〜DB〜外部API間すべて）
- データベースは保存時暗号化（AES-256、Supabase標準）
- ファイルアップロード機能なし（漏えい経路が少ない構成）

### データベースアクセス制御
- 全テーブルでRow Level Security（行レベルアクセス制御）を有効化
- **匿名アクセスで読み取れるのは「公開中の展示会名・開催情報」のみ。来場者の個人情報を匿名で読み取る経路は存在しない**（コードレビューで検証済み）
- 管理者権限キー（service_role）はサーバー側のみで使用。ブラウザに配布されるコードに含まれないことを検証済み

### 認証・認可
- 主催者管理画面: Supabase Auth（メール+パスワード）。セッションはhttpOnly/secure/sameSite Cookieで保持（XSSでの窃取・CSRFを緩和）。無効化フラグで即時利用停止可能
- 出展社画面（リード機能）: 60bit強度のアクセスコード＋httpOnly Cookie。毎リクエストDB照合のため即時失効可能。機能フラグOFFの展示会では動作しない
- QRチケットコード: 暗号学的乱数で生成（40bit・約1.1兆通り）。推測・総当たりは実用上不可能
- CRM同期バッチ: シークレットトークン認証（第三者は実行不可）

### アプリケーション
- 公開登録APIにレート制限（IPごと10回/分。スパム・総当たり対策）
- 入力値検証（形式・文字数）をAPI側で実施し、DB側でもCHECK制約で二重に強制
- メールヘッダーインジェクション対策・HTMLエスケープ実装済み
- 個人情報をアプリログに出力しない設計

### CRM連携（HubSpot）
- 同期対象は**同意文言改訂後（2026-07-13以降）の登録者のみ**。それ以前の登録者は同期しない
- 出展社ブーススキャンで取得したデータ（リード）はCRM同期の対象外
- APIトークンの権限は必要最小限の8スコープ（コンタクト/会社/リストの読み書きのみ）に限定
- 同意はチェックボックス必須＋同意日時をDBに記録（証跡）

## 3. 想定Q&A

**Q1. 登録した個人情報は誰が閲覧できますか？**
A. 展示会主催者の管理者アカウント（ログイン必須）のみです。出展社は、来場者本人がブースで入場証の提示・スキャンに応じた場合に限り、同意文言に明示した項目のみ閲覧できます。

**Q2. 匿名の第三者がデータベースに直接アクセスできませんか？**
A. できません。データベースは行レベルアクセス制御で保護され、匿名アクセスで読めるのは公開中の展示会の開催情報のみです。来場者情報の読み取りは認証済み管理者に限定されています。

**Q3. 通信・保存時の暗号化は？**
A. 全通信TLS、データベースは保存時AES-256暗号化です。

**Q4. データはどこの国に保存されますか？**
A. 個人情報を保存するメインデータベースは**国内（AWS東京リージョン ap-northeast-1）**にあります（確認日: 2026-07-13）。フォローアップ用CRM（HubSpot）への同期分およびメール送信処理は米国リージョンの事業者を利用しており、個人情報保護法の外国にある第三者（委託先）への提供として、SOC 2 Type II等の第三者認証の確認と利用目的の明示（登録フォームの同意文言）により対応しています。

**Q5. QRコード（入場証）から個人情報は読み取れますか？**
A. QRコードに含まれるのはランダムなチケットコードのみで、氏名等の個人情報は含まれません。

**Q6. 退会・削除の依頼にはどう対応しますか？**
A. 本人からの申し出により、データベースおよびCRM上の該当データを削除します（保有個人データの開示・訂正・利用停止請求に対応）。

**Q7. 展示会終了後のデータはどうなりますか？**
A. 主催者との契約に基づき取り扱います。フォローアップ目的の保持は、登録時に同意を得た「今後の展示会・関連サービスのご案内」の範囲に限定されます。案内停止はいつでも申し出可能です。

**Q8. 脆弱性対応・改修の体制は？**
A. 開発者が依存パッケージの更新と脆弱性情報を継続的に確認し、修正を適用します。過去にもセキュリティ強化改修（アクセス制御の厳格化・乱数強度の向上等）を実施済みです。
