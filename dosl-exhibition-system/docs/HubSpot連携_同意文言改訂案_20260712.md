# 登録フォーム 同意文言改訂案（HubSpot CRM連携 Phase 1）

作成日: 2026-07-12 ／ ステータス: **A案でGO・実装済み（2026-07-12・commit d483ad5）**

## 背景

DOSL GATEの登録データをDOSLのHubSpot CRMへ同期し、今後の展示会案内・リピーター管理に活用する。現行の同意文言は「主催者の展示会運営利用」と「ブーススキャン時の出展社提供」（lead_retrieval有効時のみ表示）のみで、**DOSLによる今後の展示会・関連サービスのご案内目的が含まれていない**。この目的を追記した改訂後の登録者のみをCRM同期の対象とする（`HUBSPOT_SYNC_SINCE` に改訂デプロイ日を設定して制御）。

## 現行の構成（`src/app/[slug]/register/page.tsx` L636付近）

- `features.lead_retrieval = true` の展示会のみ「個人情報の取り扱いについて」ブロック＋必須チェックボックスを表示
- 内容: ①主催者の運営利用 ②ブーススキャン時の出展社提供 ③スキャン任意 ④提供後は出展社管理
- API側: `lead_retrieval` 有効時のみ `lead_consent === true` を必須検証（`src/app/api/register/route.ts` L95-97）

## 改訂案（推奨: A案）

「個人情報の取り扱いについて」ブロックを**全展示会で常時表示**とし、箇条書きを次の構成にする。チェックボックスは現行どおり1つ（必須）。

### 表示文言

> **個人情報の取り扱いについて**
>
> - ご入力いただいた情報は、本展示会の主催者が、来場受付・本人確認・セミナー運営・統計資料の作成、および本展示会に関するご連絡のために利用します。
> - また、本登録システム「DOSL GATE」を運営するDOSL株式会社が、**今後の展示会のご案内および関連サービスのご案内**のために利用します。ご案内は、お問い合わせ窓口またはご案内メール記載の方法により、いつでも停止をお申し出いただけます。
>
> （以下、lead_retrieval 有効時のみ現行の②③④を続けて表示）
>
> - 会場内の出展社ブースで、ご自身の入場証（QRコード）を提示しスキャンを受けた場合、…（現行文言のまま）
>
> ☑ 上記の個人情報の取り扱いに同意します *

### 実装変更点（GO後に実施）

1. `page.tsx`: 同意ブロックの表示条件 `exhibition.features.lead_retrieval &&` を外して常時表示に変更。箇条書き2点目（DOSL案内目的）を追加。出展社提供の3項目は `lead_retrieval` 時のみ表示のまま
2. `route.ts`: 同意チェックの必須検証を常時に変更（現在は `lead_retrieval` 時のみ）
3. デプロイ後、Vercel環境変数 `HUBSPOT_SYNC_SINCE` にデプロイ日（ISO日付）を設定

### 影響

- lead_retrieval を使わない展示会にも必須チェックボックスが新たに表示される（登録1ステップ増）
- 既存登録者は同期対象外のまま（SINCE制御）。遡って同期したい場合は別途本人同意の取得が必要

## 代替案（B案・参考）

案内目的だけを**任意の別チェックボックス**（オプトイン）にし、同意者のみ同期する方式。プライバシー配慮としてはより丁寧だが、visitorsテーブルへの同意フラグ追加・同期処理のフィルタ追加が必要で、オプトイン率も下がるのが一般的。Phase 1はA案を推奨し、主催者向け商品化（Phase 3）の際に再検討する。

## 確認事項（GO判断時）

- 運営者名の表記: 「DOSL株式会社」で良いか（登記上の正式社名に合わせる）
- 案内停止の窓口: 問い合わせフォーム／メールどちらを案内するか
