# 指示書01: 複数展示会UI

## 目的
現状、APIは複数展示会に対応済みだがフロントが「先頭の展示会固定」（admin.html/index.htmlのinit()で`exhibitions[0]`）。
主催者が複数の展示会を作成・切替できるようにする。

## 現状
- `GET /api/exhibitions` は全展示会を返す（exhibitions.py）
- **展示会の作成・編集APIは存在しない**（一覧・summary・カテゴリCRUD・カテゴリコピーのみ）
- カテゴリコピーAPIは実装済み: `POST /api/exhibitions/{id}/submission-categories/copy-from/{src_id}`（exhibitions.py 298行目付近）
- admin.html: `exhibition = exhibitions[0]` 固定。各loaderは `exhibition.id` を参照しているので、切替は `exhibition` を差し替えて再ロードするだけでよい
- index.html（出展社ポータル）も同様に先頭固定

## 確定設計

### API（exhibitions.py に追加）
```
POST /api/exhibitions            （require_manager）201
  body: { name*, venue*, start_date*, end_date*, status?="preparing" }
PATCH /api/exhibitions/{id}      （require_manager）
  body: { name?, venue?, start_date?, end_date?, status? }
```
- status は `preparing / active / closed` のみ許可（既存データがactiveを使用）
- 日付は `YYYY-MM-DD`（pydanticで `date` 型）。end_date < start_date は400
- 削除APIは作らない（書類が紐づくため。閉幕は status=closed で表現）
- レスポンス形は既存 `GET /api/exhibitions` の1要素と同じ＋`accepting_applications`

### UI（admin.html）
1. ヘッダーの `#appTitle` の隣に展示会セレクタ `<select id="exhibitionSelect">` を置く
   - manager以外は現状どおり（セレクタは全ロールに表示してよい。作成/編集はmanagerのみ）
2. 選択値は `localStorage['doslhub_exhibition_id']` に保存。init()で
   「保存値が一覧に存在すればそれ、なければ先頭」を選ぶ
3. 切替時: `exhibition` を差し替え → `document.title`/`#appTitle` 更新 →
   カテゴリ一覧を取り直し → **現在アクティブなタブのloaderを再実行**（switchTabと同じif分岐を関数化して使う）
4. 「展示会を管理」ダイアログ（managerのみ・セレクタ横の歯車アイコン）:
   - 展示会一覧テーブル（名称・会場・会期・状態）＋「新規作成」「編集」
   - 新規作成ダイアログに「カテゴリを既存展示会からコピー」セレクト（任意）を付け、
     作成成功後に既存のカテゴリコピーAPIを呼ぶ
5. index.html（出展社ポータル）にも同じセレクタを追加（作成/編集UIは無し）。
   出展社に見せる展示会は `status != 'closed'` でフィルタ

### 注意点
- ダッシュボード・書類一覧・レビュー・注文・設計仕様・出展申込のすべてのloaderが
  `exhibition.id` を参照していることを確認済み。exhibition差し替え後の再ロードで切り替わる
- 出展申込タブの「申込ページURLコピー」は exhibition.id 入りURLなので切替後も正しく動く
- レビュー件数チップ（refreshQueueCount）と申込件数チップも切替時に更新すること

## 検証（実ブラウザ必須）
1. テストDBでseed→adminログイン→展示会を新規作成（カテゴリコピーあり/なし両方）
2. セレクタで切替→ダッシュボード/書類一覧/設計仕様が切り替わること
3. リロードして選択が保持されること
4. 出展社ログイン→index.htmlでも切替できること・closedの展示会が出ないこと
5. 既存機能のリグレッション: 書類アップロード→AI解析→レビューが従来どおり動くこと
